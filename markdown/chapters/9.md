# REGIONS SECTION


## Introduction

The [REGIONS](#__RefHeading___Toc40648_784232322) section defines how various properties in the [PROPS](#__RefHeading___Toc39329_784232322) and [SOLUTION](#__RefHeading___Toc43947_784232322) sections are allocated to individual cells within the model, as well as defining various fluid in-place reporting regions. This is accomplished by assigning an integer value to each cell that represents the data set of the property to be assigned to the grid block.
