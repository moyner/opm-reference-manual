# REGIONS SECTION


## Introduction

The [REGIONS](#kw-REGIONS) section defines how various properties in the [PROPS](#kw-PROPS) and [SOLUTION](#kw-SOLUTION) sections are allocated to individual cells within the model, as well as defining various fluid in-place reporting regions. This is accomplished by assigning an integer value to each cell that represents the data set of the property to be assigned to the grid block.
