#### Description

The [EOS](#REF_HEADING_KEYWORD_EOS_5_3) keyword specifies the Equation Of State (EOS) to be used for each EOS region. The keyword should only be used if the compositional mode has been requested using the [COMPS](#kw-COMPS) keyword in the [RUNSPEC](#kw-RUNSPEC) section.

See [EOS – Specify Equation of State](#0.0.0.EOS) in the [PROPS](#kw-PROPS) section for a full description.
