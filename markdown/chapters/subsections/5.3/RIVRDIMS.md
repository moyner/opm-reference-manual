#### Description

RIVRDIMS defines the river system array dimensions used with the [REACHES](#kw-REACHES) keyword and other river keywords in the [SOLUTION](#kw-SOLUTION) and [SCHEDULE](#kw-SCHEDULE) sections. The keyword also enables the River option.

This keyword is not supported by OPM Flow but would change the results if supported so the simulation will be stopped.
