#### Description

The AQUCWFAC keyword modifies the datum depth and pressure for all aquifers specified by the [AQUCHWAT](#kw-AQUCHWAT) keyword in the [SOLUTION](#kw-SOLUTION) or [SCHEDULE](#kw-SCHEDULE) sections.

This keyword is not supported by OPM Flow but would change the results if supported so the simulation will be stopped.
