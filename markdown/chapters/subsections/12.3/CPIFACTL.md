#### Description

The [CPIFACT](#kw-CPIFACT) keyword is used to define well Local Grid Refinement (“[LGR](#kw-LGR)”) connection transmissibility multipliers for well connections to a [LGR](#kw-LGR), for when the [LGR](#kw-LGR) option has been invoked by the [LGR](#kw-LGR) keyword in the [RUNSPEC](#kw-RUNSPEC) section.

This keyword is not supported by OPM Flow but would change the results if supported so the simulation will be stopped.
