#### Description

This keyword, DUMPCUPL, activates output to the Reservoir Coupling file from the reservoir coupling file in the master run for when reservoir coupling is invoked by the [GRUPMAST](#kw-GRUPMAST) and [SLAVES](#kw-SLAVES) keywords in the [SCHEDULE](#kw-SCHEDULE) section.

This keyword is not supported by OPM Flow but would change the results if supported so the simulation will be stopped.
