#### Description

The REACHES keyword defines the reach structure of a previously characterized river system using the [RIVERSYS](#kw-RIVERSYS) keyword in the [SCHEDULE](#kw-SCHEDULE) section. The River option must be activated via the [RIVRDIMS](#kw-RIVRDIMS) keyword in the [RUNSPEC](#kw-RUNSPEC) section in order to use these keywords.

This keyword is not supported by OPM Flow but would change the results if supported so the simulation will be stopped.
