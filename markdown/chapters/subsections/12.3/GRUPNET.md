#### Description

The [GRUPNET](#__RefHeading___Toc118319_1596574740) keyword defines the standard group network parameters used to model the flow and pressures behavior within the network. The group hierarchy is defined by the [GRUPTREE](#__RefHeading___Toc118321_1596574740) keyword and wells are assigned to groups using the [WELSPECS](#__RefHeading___Toc268463_1366622701) keyword, both keywords are in the [SCHEDULE](#__RefHeading___Toc43945_784232322) section.

Group pressure values are optionally entered for each group in the network together with a vertical flow (lift) performance (“VFP”) table that the determines the pipeline pressure behavior from the LOWER to the HIGHER group given the current flowing conditions; the group relationship is defined by the [GRUPTREE](#__RefHeading___Toc118321_1596574740) keyword.  The VFP table is entered via the [VFPPROD](#__RefHeading___Toc121919_2556401936) keyword for production pipelines and [VFPINJ](#__RefHeading___Toc121917_2556401936) for injection pipelines. These are the same keywords as used for well modeling, however, the manner in which they are generated by an external program is completely different when used for pipeline modeling.

#### Examples

The following example defines a network based on two groups


```
--
--       DEFINE GROUP STANDARD NETWORK PARAMETERS
--
-- GRUP  CNTL   VFP    PUMP   MANIFOLD  INCLUDE   ALQ
-- NAME  PRES   TABLE  POWER  GROUP     LIFT GAS  DENS
GRUPNET
PROD-A   1200.  1*                                                             /
PROD-B   1*     1      1*    'YES'      1*        1*                           /
/

```

The next example is more complex and is taken form the Norne model.


```
--
--       DEFINE GROUP STANDARD NETWORK PARAMETERS
--
-- GRUP  CNTL   VFP    PUMP   MANIFOLD  INCLUDE   ALQ
-- NAME  PRES   TABLE  POWER  GROUP     LIFT GAS  DENS
GRUPNET
FIELD    20.0   5*                                                             /
PROD     20.0   5*                                                             /
MANI-B2  1*     8      1*      NO       2*                                     /
MANI-B1  1*     8      1*      NO       2*                                     /
MANI-K1  1*    9999    4*                                                      /
B1-DUMMY 1*    9999    4*                                                      /
MANI-D1  1*     8      1*      NO       2*                                     /
MANI-D2  1*     8      1*      NO       2*                                     /
MANI-K2  1*    9999    4*                                                      /
D2-DUMMY 1*    9999    4*                                                      /
MANI-E1  1*     9      1*      NO       2*                                     /
MANI-E2  1*     9      4*                                                      /
/
```


Here the [FIELD](#__RefHeading___Toc71850_2267116897) controlling pressure is set at 20 barsa and the same limit is used for group PROD which sits directly under the FIELD group (see Figure 12.4).
