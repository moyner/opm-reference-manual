#### Description

This keyword, GCUTBACT, defines a production group’s cutback limits and parameters based on the named produced tracer from the group. See also the [WCUTBACT](#kw-WCUTBACT) keyword in the [SCHEDULE](#kw-SCHEDULE) section that provides similar functionality for groups.

This keyword is not supported by OPM Flow but would change the results if supported so the simulation will be stopped.
