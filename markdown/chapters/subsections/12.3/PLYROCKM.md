#### Description

The PLYROCKM keyword modifies rock properties entered via the [PLYCAMAX](#kw-PLYCAMAX), [PLYKRRF](#kw-PLYKRRF), [PLYRMDEN](#kw-PLYRMDEN), and [PLYROCK](#kw-PLYROCK) keywords in the [PROPS](#kw-PROPS) section, for when the Polymer option has been activated by the [POLYMER](#kw-POLYMER) keyword in the [RUNSPEC](#kw-RUNSPEC) section.

This keyword is not supported by OPM Flow but would change the results if supported so the simulation will be stopped.
