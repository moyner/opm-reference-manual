#### Description

The GNETPUMP keyword defines the configuration of automatic compressors and pumps in a production Standard Network, for when the Standard Network option is invoked by the [GRUPTREE](#kw-GRUPTREE), GRUPNET, [GNETINJE](#kw-GNETINJE), GNETPUMP, etc., series of keywords in the [SCHEDULE](#kw-SCHEDULE) section. Although several keywords can be used by both the Standard and Extended Network options, GNETPUMP can only be used with the Standard Network option. The equivalent keyword for the Extended Network option is the [NETCOMPA](#kw-NETCOMPA) keyword in the [RUNSPEC](#kw-RUNSPEC) section.

This keyword is not supported by OPM Flow but would change the results if supported so the simulation will be stopped.
