#### Description

This keyword, SLAVES, defines the name of the slave reservoirs and their associated simulation input files, for when the Reservoir Coupling option has been declared active by the [GRUPMAST](#kw-GRUPMAST) and SLAVES keywords in the [SCHEDULE](#kw-SCHEDULE) section.

This keyword is not supported by OPM Flow but would change the results if supported so the simulation will be stopped.
