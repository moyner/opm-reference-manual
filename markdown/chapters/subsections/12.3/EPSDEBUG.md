### EPSDEBUG – Write End-Point Debug Data to the DEBUG File (Individual) {#kw-EPSDEBUG}

This keyword, EPSDEBUG, defines the end-point debug data for individual grid blocks that should be written to the Debug file (*.DBG) for when the End-Point Scaling option has been activated by the [ENDSCALE](#kw-ENDSCALE) keyword in the [RUNSPEC](#kw-RUNSPEC) section.

See EPSDEBUG - Write End-Point Debug Data to the [DEBUG](#kw-DEBUG) File (Individual)n the [PROPS](#kw-PROPS) section for afull description.
