#### Description

This keyword, RPTHMG, either enables or disables history match output reporting to the history match file (*.HMD) for the named group, for when the History Match Gradient option has been activated by the [HMDIMS](#kw-HMDIMS) keyword in the [RUNSPEC](#kw-RUNSPEC) section.

This keyword is not supported by OPM Flow but has no effect on the results so it will be ignored.
