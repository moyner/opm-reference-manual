### EPSDBGS – Write End-Point Debug Data to the DEBUG File (Multiple) {#kw-EPSDBGS}

This keyword, EPSDBGS, defines the end-point debug data for multiple grid blocks that should be written to the debug file (*.DBG) for when the End-Point Scaling option has been activated by the [ENDSCALE](#kw-ENDSCALE) keyword in the RONSPEC section.

See EPSDBGS - Write End-Point Debug Data to the [DEBUG](#kw-DEBUG) File (Multiple) in the [PROPS](#kw-PROPS) section for afull description.
