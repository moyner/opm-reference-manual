#### Description

The ACTION keyword defines a series of conditions that invoke run time processing of ACTION functions and is similar to executing a run time script for conditions and variables at the field level.

This keyword is not supported by OPM Flow but would change the results if supported so the simulation will be stopped; use the [ACTIONX](#kw-ACTIONX) keyword instead.
