### AQUFETP – Define Fetkovich Analytical Aquifers {#kw-AQUFETP}

The AQUFETP keyword defines Fetkovich Analytical aquifers and the aquifer properties. Each row entry in the AQUFETP keyword defines one Fetkovich Analytical aquifer. In order to fully define this type of aquifer, the aquifer must be connected to the reservoir using the [AQUANCON](#kw-AQUANCON) keyword in the [GRID](#kw-GRID) or [SOLUTION](#kw-SOLUTION) sections.

See AQUFETP – Define Fetkovich Analytical Aquifers  in the [SOLUTION](#kw-SOLUTION) section for a full description.
