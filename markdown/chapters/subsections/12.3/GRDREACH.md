#### Description

The GRDREACH keyword defines the location of grid blocks connecting to a previously defined river, for when the River option has been activated via the [RIVRDIMS](#kw-RIVRDIMS) keyword in the [RUNSPEC](#kw-RUNSPEC) section.

This keyword is not supported by OPM Flow but would change the results if supported so the simulation will be stopped.
