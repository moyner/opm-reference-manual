#### Description

The WCONINJ is a legacy keyword that is no longer used in the commercial simulator and is not supported by OPM Flow. Instead well injection targets and constraints should be defined using the [WCONINJE](#kw-WCONINJE) keyword in the [SCHEDULE](#kw-SCHEDULE) section.

This keyword is not supported by OPM Flow but would change the results if supported so the simulation will be stopped.
