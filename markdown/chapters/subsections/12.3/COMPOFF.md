#### Description

The COMPOFF keyword deactivates network automatic compressors defined via the [GASFCOMP](#kw-GASFCOMP) keyword in the [SCHEDULE](#kw-SCHEDULE) section.

This keyword is not supported by OPM Flow but would change the results if supported so the simulation will be stopped.
