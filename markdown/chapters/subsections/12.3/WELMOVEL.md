#### Description

This keyword, WELMOVEL, moves a previously defined gloabal well into a previously declared Local Grid Refinement (“[LGR](#kw-LGR)”), in a [RESTART](#kw-RESTART) run.  The keyword should only be used in [RESTART](#kw-RESTART) runs.

This keyword is not supported by OPM Flow but would change the results if supported so the simulation will be stopped.
