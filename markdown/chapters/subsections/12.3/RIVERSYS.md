### RIVERSYS – Define River System (Branch Structure and Boundary Conditions) {#kw-RIVERSYS}

RIVERSYS defines a river system by specifying the branch structure of the river together with the branch's associated boundary conditions, for when the River option has been activated via the [RIVRDIMS](#kw-RIVRDIMS) keyword in the [RUNSPEC](#kw-RUNSPEC) section.

See RIVERSYS - Define River System (Branch Structure and Boundary Conditions) in the [SOLUTION](#kw-SOLUTION) section for a full description.
