#### Description

The DIFF keyword defines the coal bed methane diffusion data for when the Coal Bed Methane option has been activated via the [COAL](#kw-COAL) keyword in the [RUNSPEC](#kw-RUNSPEC) section.

This keyword is not supported by OPM Flow but would change the results if supported so the simulation will be stopped.
