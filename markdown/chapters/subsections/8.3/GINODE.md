#### Description

The GINODE keyword defines the Gi node values used when the [GIMODEL](#kw-GIMODEL) keyword in the [RUNSPEC](#kw-RUNSPEC) section has been used to activate the [GI](#kw-GI) Pseudo Compositional option for the run. The keyword is used in conjunction with the [RSGI](#kw-RSGI), [RVGI](#kw-RVGI), [BGGI](#kw-BGGI) and [BOGI](#kw-BOGI) keywords in the [PROPS](#kw-PROPS) section to describe the fluid properties for the [GI](#kw-GI) Pseudo Compositional option.

This keyword is not supported by OPM Flow but would change the results if supported so the simulation will be stopped.
