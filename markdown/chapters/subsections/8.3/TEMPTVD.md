#### Description

TEMPTVD activates the Temperature Flux Limited Transport option in the commercial simulator, to reduce numerical dispersion for when either the [TEMP](#kw-TEMP) or [THERMAL](#kw-THERMAL) keywords in the [RUNSPEC](#kw-RUNSPEC) section have been declared.


This keyword is not supported by OPM Flow but would change the results if supported so the simulation will be stopped.
