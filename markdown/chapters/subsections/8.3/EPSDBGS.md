#### Description

This keyword, EPSDBGS, defines the end-point debug data for multiple grid blocks that should be written to the [DEBUG](#kw-DEBUG) file (*.DBG) for when the End-Point Scaling option has been activated by the [ENDSCALE](#kw-ENDSCALE) keyword in the RONSPEC section.

This keyword is not supported by OPM Flow but has no effect on the results so it will be ignored.
