#### Description

The ALKROCK keyword defines the rock alkaline properties for when the alkaline model has been activated via the [ALKALINE](#kw-ALKALINE) keyword in the [RUNSPEC](#kw-RUNSPEC) section.

This keyword is not supported by OPM Flow but would change the results if supported so the simulation will be stopped.
