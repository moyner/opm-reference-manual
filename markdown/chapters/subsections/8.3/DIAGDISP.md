#### Description

This keyword, DIAGDISP,  activates the alternate form of tracer dispersion matrix for when the Tracer facility has been activated by the [TRACERS](#kw-TRACERS) keyword in the [RUNSPEC](#kw-RUNSPEC) section.

This keyword is not supported by OPM Flow but would change the results if supported so the simulation will be stopped.
