#### Description

The HDISP keyword is combined with three character tracer name, specified by the [TRACER](#kw-TRACER) keyword in the  [PROPS](#kw-PROPS) section, to define the tracer’s mechanical dispersivity parameters.

This keyword is not supported by OPM Flow but would change the results if supported so the simulation will be stopped.
