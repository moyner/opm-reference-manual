#### Description

The GIALL keyword defines the [GI](#kw-GI) values and the associated [RVGI](#kw-RVGI), [RSGI](#kw-RSGI), [BGGI](#kw-BGGI) and [BOGI](#kw-BOGI) values as a function of pressure, for when the [GI](#kw-GI) Pseudo Compositional option has been activated in the model via the [GIMODEL](#kw-GIMODEL) keyword in the [RUNSPEC](#kw-RUNSPEC) section.

This keyword is not supported by OPM Flow but would change the results if supported so the simulation will be stopped.
