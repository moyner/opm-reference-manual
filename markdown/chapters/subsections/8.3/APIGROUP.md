#### Description

The APIGROUP keyword defines the maximum number of groups of oil PVT tables when the [API](#kw-API) tracking option has been activated via the [API](#kw-API) keyword in the [RUNSPEC](#kw-RUNSPEC) section.

This keyword is not supported by OPM Flow but would change the results if supported so the simulation will be stopped.
