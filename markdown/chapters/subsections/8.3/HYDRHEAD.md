#### Description

The HYDRHEAD keyword defines the hydraulic head reference data for when the hydraulic head information is requested to be written out via one on the [SUMMARY](#kw-SUMMARY) keywords (BHD, BHDF, etc.) in the [SUMMARY](#kw-SUMMARY) section, or to the [RESTART](#kw-RESTART) file via the HYDH or HYDHFW variables on the [RESTART](#kw-RESTART) keyword

This keyword is not supported by OPM Flow but would change the results if supported so the simulation will be stopped.
