### GETDATA – Load and Assign Data Array from INIT or RESTART File {#kw-GETDATA}

The GETDATA keyword loads a data array from a previously generated [INIT](#kw-INIT) or [RESTART](#kw-RESTART) file and assigns the loaded array to either same array in the run or another array name.

See GETDATA – Load and Assign Data Array from [INIT](#kw-INIT) or [RESTART](#kw-RESTART) Files in the [GRID](#kw-GRID) section for a full description.
