#### Description

The FHERCHBL keyword defines Herschel-Bulkley rheological property data for Non-Newtonian fluids versus polymer concentration, for when the Polymer option has been invoked via the [POLYMER](#kw-POLYMER) keyword in the [RUNSPEC](#kw-RUNSPEC) section and Non-Newtonian Fluid phase has been declared active by the [NNEWTF](#kw-NNEWTF) keyword, also in the [RUNSPEC](#kw-RUNSPEC) section.

This keyword is not supported by OPM Flow but would change the results if supported so the simulation will be stopped.
