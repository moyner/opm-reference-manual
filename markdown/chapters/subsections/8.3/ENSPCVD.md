#### Description

This keyword defines the variation of the capillary pressure saturation end-points, connate gas ([SGL](#kw-SGL)) and connate water ([SWL](#kw-SWL)), versus depth for when the end-point scaling option has been invoked by the [ENDSCALE](#kw-ENDSCALE) keyword in the [RUNSPEC](#kw-RUNSPEC) section. This functionality is not supported in OPM Flow.

This keyword is not supported by OPM Flow but would change the results if supported so the simulation will be stopped.
