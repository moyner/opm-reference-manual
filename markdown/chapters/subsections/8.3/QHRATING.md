#### Description

The QHRATING keyword defines a river’s mass flow rate versus depth tables, for when the River option has been activated via the [RIVRDIMS](#kw-RIVRDIMS) keyword in the [RUNSPEC](#kw-RUNSPEC) section.

This keyword is not supported by OPM Flow but would change the results if supported so the simulation will be stopped.
