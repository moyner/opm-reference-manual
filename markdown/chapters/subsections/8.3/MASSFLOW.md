#### Description

The MASSFLOW keyword defines the upstream river mass flow versus time tables for rivers, for when the River option has been activated via the [RIVRDIMS](#kw-RIVRDIMS) keyword in the [RUNSPEC](#kw-RUNSPEC) section.

This keyword is not supported by OPM Flow but would change the results if supported so the simulation will be stopped.
