### MESSAGE – Output User Message {#kw-MESSAGE}

The MESSAGE keyword outputs a user message to the terminal, as well as to the print (*.PRT) and debug  (*.DBG) files.  Note this is different to the [MESSAGES](#kw-MESSAGES) keyword, that defines OPM Flows message print limits and stop limits generated by the simulator.

See MESSAGE – Output User Message in the GLOBAL section for a full description.
