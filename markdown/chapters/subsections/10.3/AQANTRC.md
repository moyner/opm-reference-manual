#### Description

The AQANTRC keyword defines the initial tracer concentrations for analytic aquifers that have previously been defined by the AQCT keyword in the [GRID](#kw-GRID), [PROPS](#kw-PROPS), or [SOLUTION](#kw-SOLUTION) sections for Carter-Tracy analytical aquifers, or the AQFET and AQFETP keywords in the [SOLUTION](#kw-SOLUTION) section for Fetkovich analytical aquifers.

This keyword is not supported by OPM Flow but would change the results if supported so the simulation will be stopped.
