### BOX – Define a Range of Grid Blocks to Enter Property Data {#kw-BOX}

BOX defines a range of grid blocks for which subsequent data is assigned for all the cells in the defined BOX. Note that the BOX grid is reset by the keyword [ENDBOX](#kw-ENDBOX) by resetting the current defined BOX to be the  whole grid. The keyword can be used for any array and for all grid types.

See  BOX -  Define a Range of Grid Blocks to Enter Property Data in the [GRID](#kw-GRID) section for a full description.
