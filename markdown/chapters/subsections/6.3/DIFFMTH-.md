#### Description

The [DIFFMR-](#kw-DIFFMR-) keyword defines the negative theta direction diffusivity multipliers for cells in the current input box for when the Diffusivity option has been activated by the [DIFFUSE](#kw-DIFFUSE) keyword in the [RUNSPEC](#kw-RUNSPEC) section.

This keyword is not supported by OPM Flow but would change the results if supported so the simulation will be stopped.
