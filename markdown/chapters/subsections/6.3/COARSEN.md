#### Description

The COARSEN keyword defines how a set of cells should be coarsened for when the Local Grid Refinement (“[LGR](#kw-LGR)”) option has been activated by [LGR](#kw-LGR) keyword in the [RUNSPEC](#kw-RUNSPEC) section.

This keyword is not supported by OPM Flow but would change the results if supported so the simulation will be stopped.
