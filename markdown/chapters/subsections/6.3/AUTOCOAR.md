#### Description

The AUTOCOAR keyword defines an area in the global grid that should be coarsen for when the [AUTOREF](#kw-AUTOREF) keyword has been declared in the [RUNSPEC](#kw-RUNSPEC) section.

This keyword is not supported by OPM Flow but would change the results if supported so the simulation will be stopped.
