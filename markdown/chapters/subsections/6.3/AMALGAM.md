#### Description

The AMALGAM keyword defines a Cartesian Local Grid Refinements (“[LGR](#kw-LGR)”) amalgamations, that is  merging several LGRs into one amalgamated [LGR](#kw-LGR).

This keyword is not supported by OPM Flow but would change the results if supported so the simulation will be stopped.
