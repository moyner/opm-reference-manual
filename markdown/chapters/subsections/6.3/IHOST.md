#### Description

The IHIST keyword assigns Local Grid Refinements (“[LGR](#kw-LGR)”) to a parallel process number, for when the [PARALLEL](#kw-PARALLEL) keyword has been invoked in the [RUNSPEC](#kw-RUNSPEC) section.

This keyword is not supported by OPM Flow but would change the results if supported so the simulation will be stopped.
