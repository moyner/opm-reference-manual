#### Description

The COLLAPSE keyword defines the which cells can be collapsed in a collapsed Vertical Equilibrium (“[VE](#kw-VE)”) run when the [VE](#kw-VE) option has been invoked via the [VE](#kw-VE) keyword in the [RUNSPEC](#kw-RUNSPEC) section.

This keyword is not supported by OPM Flow but would change the results if supported so the simulation will be stopped.
