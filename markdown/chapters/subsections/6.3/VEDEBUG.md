#### Description

This keyword defines the debug Vertical Equilibrium (“[VE](#kw-VE)”) data to be written to the debug file (*.DBG), for when the [VE](#kw-VE) model has been activated by the [VE](#kw-VE) keyword in the [RUNSPEC](#kw-RUNSPEC) section.

This keyword is not supported by OPM Flow but would change the results if supported so the simulation will be stopped.
