### ENDFIN – End the Definition of a Local Grid Refinement {#kw-ENDFIN}

NDFIN defines the end of a Cartesian or radial local grid refinement (“[LGR](#kw-LGR)”) definition and a [LGR](#kw-LGR) property definition data set.

See ENDFIN – End the Definition of a Local Grid Refinement in the [GRID](#kw-GRID) section for a full description.
