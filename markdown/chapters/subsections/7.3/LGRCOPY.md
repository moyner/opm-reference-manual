### LGRCOPY – Activate Local Grid Refinement Inheritance {#kw-LGRCOPY}

The LGRCOPY keyword actives Local Grid Refinement (“[LGR](#kw-LGR)”) Inheritance option that allows the [LGR](#kw-LGR) to inherit the properties of the global or host cell containing a [LGR](#kw-LGR) grid block at the start of the [GRID](#kw-GRID) section, as oppose to the normal process of applying this transform at the end of the [GRID](#kw-GRID) section. LGRCOPY can be used in the [RUNSPEC](#kw-RUNSPEC), [GRID](#kw-GRID) and [EDIT](#kw-EDIT) sections. If used in the [RUNSPEC](#kw-RUNSPEC) section then the option is applied to all LGRs defined in the input file, whereas if used in the [GRID](#kw-GRID) and [EDIT](#kw-EDIT) sections the keyword must be placed inside a [LGR](#kw-LGR) definition section, that is between a [CARFIN](#kw-CARFIN) (Cartesian [LGR](#kw-LGR) grid) or RADIN/RADIN4 (radial [LGR](#kw-LGR) grid) and the [ENDFIN](#kw-ENDFIN) keyword. In the latter case inheritance is applied on an individual [LGR](#kw-LGR) basis.

See LGRCOPY – Activate Local Grid Refinement Inheritance in the [RUNSPEC](#kw-RUNSPEC) section for a full description.
